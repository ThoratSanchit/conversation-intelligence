# conversation-intelligence

An intelligence and action layer built on top of SaaSquatch-enriched lead data.

## Stack
- **Backend**: Fastify, TypeScript, PostgreSQL, Sequelize ORM, Zod, Papa Parse, OpenAI
- **Frontend** (upcoming): React, TypeScript, Vite, Tailwind CSS, Lucide React

## Project Structure
- `server/`: Backend REST API and Conversation Intelligence engine
